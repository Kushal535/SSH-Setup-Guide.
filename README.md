## Project Overview
This repository will contain a comprehensive tutorial and working automation scripts for setting up secure remote login using SSH. The project involves setting up an SSH server, generating public/private key pairs, disabling password-based authentication in favor of key-based authentication, and configuring a non-default port for added security

## Action Plan
1. Set up Linux environment (WSL2/Ubuntu) on Windows
2. Install and configure OpenSSH server
3. Generate SSH key pair; configure key-based authentication; disable password authentication; change default port
4. Write automation scripts (key generation, config verification, service restart)
5. Write a step-by-step tutorial document and compile screenshots.

## Expected Impact
Completing this project will strengthen practical understanding of secure remote access and system hardening. It builds foundational Linux and Bash scripting skills, and will produce a genuine, reusable technical artifact (a working SSH hardening guide) that can be added to a personal portfolio
